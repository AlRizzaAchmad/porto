# Portfolio Al Rizza

Website portofolio pribadi dengan HTML, CSS, dan JavaScript murni.

## Menjalankan di VS Code
1. Ekstrak `portfolio-al-rizza.zip`.
2. Buka folder `portfolio-al-rizza` di Visual Studio Code.
3. Buka `index.html` di browser, atau pasang ekstensi **Live Server**.
4. Jika memakai Live Server, klik kanan `index.html` lalu pilih **Open with Live Server**.

## Bagian yang wajib disesuaikan
- `index.html`: nama, deskripsi, kampus, lokasi, daftar proyek, tautan GitHub/LinkedIn.
- Ganti `emailkamu@example.com` dengan alamat email aktif (ada pada tombol dan bagian kontak).
- Ganti tautan `https://github.com/` dan `https://www.linkedin.com/` dengan profil milikmu.
- Jika ingin foto asli, ubah elemen `.avatar` di `index.html` menjadi tag `<img>` dan atur tampilannya di `style.css`.

## Catatan
Contoh proyek Display Informasi Masjid dan Catatan Keuangan Pribadi sudah disiapkan berdasarkan arah proyek yang pernah dikerjakan/dikembangkan. Pastikan deskripsi dan status setiap proyek sesuai hasil sebenarnya sebelum dipublikasikan.

Font Google Fonts membutuhkan koneksi internet. Tanpa koneksi, website tetap tampil dengan font cadangan.
